# Data Professional Survey Breakdown

## Project Overview
This project is an interactive Power BI dashboard that analyzes survey responses from data professionals.  
It provides insights into career paths, job roles, salaries, skills, and overall trends in the data industry.

The goal is to better understand the profile of data professionals and identify key patterns in the field.

---

## Tools & Technologies
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Data Cleaning in Power Query
- Excel / CSV dataset (survey data)
